This is a fork of the excellent work done by Brian Harper, M1CEM. 
It is an audio DSP capable of implementing different noise and interference reduction techniques. 

I have created an Action github that allows you to have the latest firmware compiled directly from the sources present. 
The firmware to be loaded on the microcontroller is located on the path: 

    https://github.com/gcallipo/M1CEM/tree/main/latest_build_firmware 
    
I recommend that you clone the entire project to download it using the green button and save everything as a zip file, 
this will ensure that the binaries will not be corrupted by the direct download.
